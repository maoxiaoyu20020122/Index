# Index Timing Research

本项目用于检验中证500、中证1000和科创50指数的日频择时因子。

## 当前内容

- `src/index_timing_research.py`：指数行情拉取、因子构建、IC 检验和择时回测脚本。
- `research_notes.md`：从研报和论文中抽取的指数择时方法摘要。
- `outputs/summary.md`：本次回测摘要。
- `outputs/factor_ic.csv`：单因子未来收益 IC、胜率和分组收益。
- `outputs/timing_performance.csv`：单因子和综合信号的择时绩效。

## 指数范围

- 中证500：`000905.SH`
- 中证1000：`000852.SH`
- 科创50：`000688.SH`

## 方法概览

因子池包括均线趋势、时间序列动量、快慢动量转折、波动率状态、成交额确认、突破位置、区间位置、短期反转、日内强弱、振幅收缩和滚动 IC 定向综合信号。

外生数据包括：

- 宽基/风格指数：上证指数、沪深300、上证50、创业板指、中证全指。
- 利率流动性：SHIBOR 隔夜、1周、1月、3月及变化。
- 资金情绪：融资融券余额/买入/偿还、沪深港通资金流。
- 风格扩散：小盘相对大盘、成长相对沪深300、目标指数相对沪深300。

信号在当日收盘后形成，次一交易日生效，避免未来函数。

## 复现方式

```bash
pip install pandas numpy scipy tushare
TUSHARE_TOKEN=你的token python3 src/index_timing_research.py
```

默认样本区间为 `20150101` 至 `20260902`，交易成本为单边 2 bps。

## 初步结论

中证500和中证1000上，传统趋势、均线和动量因子单独效果偏弱；引入外生数据后，创业板20日动量对中证500和中证1000的短期择时改善最明显。科创50对创业板成交额热度、自身成交额放大、北向资金和利率环境更敏感，当前更值得继续深挖。

后续建议继续加入商品、汇率、期限利差、信用利差和宏观景气高频代理，并增加滚动样本外评估。
